# Face Mask Detection System 😷

A Computer Vision and Machine Learning project designed to detect whether a person is wearing a face mask or not. The system analyzes facial images and identifies the mask status, helping support basic safety monitoring.

## 🚀 Features

- Detects faces in images or through a camera.
- Classifies faces into:
  - **Mask**
  - **No Mask**
- Displays the detection result.
- Supports real-time detection (if webcam functionality is implemented).
- Provides a simple approach to automated face mask monitoring.

## 🛠️ Technologies Used

- Python
- Computer Vision
- Machine Learning / Deep Learning
- OpenCV
- NumPy


## ⚙️ Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd Face-Mask-Detection
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Usage

Run the main application:

```bash
python main.py
```

Follow the application instructions to perform face mask detection.

## 🎯 Project Objective

The main objective of this project is to explore computer vision and machine learning techniques for identifying face mask usage. It demonstrates how automated image analysis can be applied to basic public safety monitoring.
